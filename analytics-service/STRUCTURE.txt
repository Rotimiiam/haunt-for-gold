API Endpoints Summary:
├── POST /api/analytics/visit        # Track visits
├── POST /api/analytics/game/start   # Track game start
├── POST /api/analytics/game/end     # Track game end
├── POST /api/analytics/pageview     # Track page views
├── POST /api/analytics/session/end  # End session
├── GET  /api/analytics/visits/total # Get total visits
├── GET  /api/analytics/games/modes  # Get game mode stats
├── GET  /api/analytics/sessions/active  # Get active sessions
├── GET  /api/analytics/games/completion # Get completion rates
├── GET  /api/analytics/pageviews    # Get page views
├── GET  /api/analytics/engagement   # Get engagement metrics
├── GET  /api/analytics/peak-usage   # Get peak usage times
└── GET  /api/analytics/dashboard    # Get dashboard data

Metrics Tracked:
├── Total visit counts
├── Unique sessions
├── Game mode usage (practice, online, local)
├── Active user sessions
├── Concurrent players
├── Game completion rates
├── Page views
├── User engagement duration
└── Peak usage times (hourly & daily)
